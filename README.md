# VirgoFash 

**VirgoFash** is a lightweight, zero-dependency asynchronous search and answer engine built in pure Python. It is designed for fast, local-first web search extraction, snippet ranking, and robust query handling without relying on heavy external APIs or paid LLMs.

---

## 🛠️ Key Features

* **Asynchronous Architecture:** Built using native `async/await` and `httpx` for high-performance concurrent web requests.
* **Zero Heavy Dependencies:** Keeps your environment clean and lightweight.
* **Deterministic Scoring & Ranking:** Automatically extracts and scores search snippets based on relevance.
* **Local-First Design:** Operates smoothly without mandatory AI model or paid API keys.
